# AI Tracker 手动测试执行指南

## 测试环境准备

### 1. 启动服务
确保前后端服务都在运行：

```bash
# 终端 1: 启动后端
cd /Users/yelon/Documents/werss/ai-tracker/backend
npm run dev

# 终端 2: 启动前端
cd /Users/yelon/Documents/werss/ai-tracker/frontend
npm run dev
```

### 2. 访问应用
- 前端地址: http://localhost:5173 (或实际运行的端口)
- 后端地址: http://localhost:3000
